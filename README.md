# Северная Сага

Пиксельный платформер в славянско-скандинавском духе на движке [Pyxel](https://github.com/kitao/pyxel).
Сейчас в игре три локации:

- **Велеград** — стартовый город: центральная площадь со Стелой Предков, избы,
  длинный дом, кузница, торговые ряды и жители, с которыми можно поговорить.
- **Лесная тропа** — пробный уровень с волками и драуграми (обычными, со щитами
  и лучниками). Вход — через восточные ворота города, назад — по левому краю тропы.
- **Курган ярла** — логово первого босса, ярла-драугра Хрёрека. Вход — через врата
  в конце лесной тропы. Перед ареной есть рунный камень.

У гридницы в городе есть тренировочный двор с чучелами: воевода Свенельд объясняет приёмы.

## Бой

- **Выносливость** (зелёная полоска под жизнью) тратится на удары, перекат и блок.
- **Серия** из трёх ударов — жмите удар во время взмаха; третий удар сильнее.
- **Тяжёлый удар** — удерживайте удар после взмаха и отпустите, когда оружие вспыхнет.
  Пробивает щиты.
- **Удар сверху** — в прыжке вниз + удар; от врага отскакиваете вверх.
- **Блок щитом** гасит удар ценой выносливости; без щита часть урона проходит.
  Кончились силы — щит пробит, и герой оглушён.
- **Парирование** — поднимите щит прямо перед ударом. Враг оглушён, следующий удар
  по нему критический. Парированная стрела летит обратно.
- **Перекат** — короткая неуязвимость, сквозь врагов и стрелы.

## Запуск

```bash
pip install -U pyxel
python main.py
```

## Босс: ярл-драугр Хрёрек

- **Серия из трёх ударов секирой** — каждый удар можно парировать; парированный
  ярл оглушён, и удар по нему критический.
- **Прыжок с ударом оземь** — по полу бегут ударные волны: перепрыгните их,
  прокатитесь сквозь них или уйдите на уступ.
- **Круговой удар** (вторая фаза) — ярл вспыхивает красным: щитом не отразить, отступайте.
- На половине здоровья ярл впадает в ярость: зовёт двух волков и атакует быстрее.

После победы решётка арены поднимается, появляется сундук с секирой ярла,
открывается выход, а игра сохраняется. Побеждённый ярл больше не возвращается.

## Управление

| Действие | Клавиши |
|---|---|
| Идти | ← → / A D |
| Прыжок | Пробел / Z / K |
| Удар (удерживать — тяжёлый удар) | X / J |
| Удар сверху (в прыжке) | ↓ + удар |
| Щит, парирование | C / L |
| Перекат | V / Shift |
| Спрыгнуть с доски | ↓ + прыжок |
| Говорить, открыть сундук, поклониться Стеле / рунному камню, войти во врата | ↑ / W |
| Подлечиться (съесть припасы) | Q / H |
| Сума и снаряжение | I / Tab |
| Пауза | Esc / P |
| Музыка вкл/выкл | M |
| Во весь экран | Alt+Enter |

Геймпад тоже поддерживается.

## Сохранение

Игра сохраняется у Стелы Предков в городе и у рунных камней в лесу (они заодно
восстанавливают здоровье), а также через меню паузы. Файл сохранения: `saves/save.json`.
Сохраняются локация и положение героя, здоровье, сума, снаряжение, серебро, собранные
предметы и открытые сундуки во всех локациях. Враги после загрузки появляются снова.

## Как устроен файл локации

Локации — текстовые файлы в `game/levels/`, их можно править вручную.
Символы карты описаны в шапке файлов. Остальное задаётся разделами
(координаты — столбец и строка тайла, счёт с нуля):

| Раздел | Пример | Смысл |
|---|---|---|
| `[meta]` | `title = Велеград`, `sky = town`, `music = 1` | название, фон (`town`/`forest`), музыка |
| `[spawns]` | `from_forest = 101,19` | именованные точки появления героя |
| `[exits]` | `106,19 = test_level from_town town` | куда ведут врата `E` и выходы `X`; `end` — финал |
| `[chests]` | `29,19 = honey` | содержимое сундуков |
| `[signs]` | `100,19 = Лесная тропа` | тексты табличек |
| `[npcs]` | `45,19 = elder` | где стоят жители (облик и реплики — в `npcs.py`) |
| `[props]` | `izba 21,19 8` | постройки: вид, левый нижний тайл, ширина |

Для арены босса в `[meta]` есть ещё `boss` (кто), `arena_trigger` (столбец, за которым
босс просыпается), `arena_door` (решётка: столбец, верхняя и нижняя строки) и
`boss_chest` (сундук-награда, появляется после победы).
